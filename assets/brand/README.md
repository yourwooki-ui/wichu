# WICHU Brand Assets

- `wichu-brand-board.png`: 사용자가 제공한 브랜드 기준 보드
- `wichu-wordmark-glow-reference.png`: 사용자가 제공한 다크 워드마크 참고 이미지
- `wichu-app-icon.png`: 기준 보드에서 파생한 Expo 앱 아이콘
- `wichu-splash.png`: 기준 보드에서 파생한 Expo 네이티브 스플래시

원본 기준 이미지는 수정하지 않습니다. 파생 파일을 교체할 때는 `app.config.js`의 `icon`, Android adaptive icon, `expo-splash-screen` 경로도 함께 검증합니다.
