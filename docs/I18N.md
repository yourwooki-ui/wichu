# WICHU 언어 정책

## 앱 UI 언어

앱 메뉴, 버튼, 가입 안내에 적용되는 언어다. 기기 언어를 최초 기본값으로 사용하고 사용자가 선택한 값은 `wichu.app-language.v2`에 저장한다.

- 한국어 (`ko`)
- 영어 (`en`)
- 베트남어 (`vi`)
- 일본어 (`ja`)
- 프랑스어 (`fr`)
- 스페인어 (`es`)
- 중국어 번체·대만 (`zh-TW`)
- 인도네시아어 (`id`)
- 페르시아어 (`fa`, RTL)

지원하지 않는 기기 언어의 기본값은 영어다. 중국어 번체 계열(`zh-Hant`, `zh-TW`, `zh-HK`, `zh-MO`)은 `zh-TW`로 정규화한다. 웹에서는 선택 즉시 문서의 `lang`과 `dir`을 변경하고, 앱 루트도 LTR/RTL 방향을 따른다.

## 프로필 언어

모국어와 구사 가능한 언어·수준은 다른 사용자에게 보여주는 프로필 데이터다. 앱 UI 언어와 별도 상태, 별도 저장 경로를 사용하며 앱 언어를 바꿔도 프로필 언어는 변경되지 않는다.

## 번역 원칙

- 영어 리소스를 최종 fallback으로 사용한다.
- 로그인, 가입, 프로필 생성, 프로필 상세, 하단 탭, 설정은 출시 핵심 번역 범위다.
- 새 사용자 문구는 화면에 직접 작성하지 않고 i18n 키로 추가한다.
- 번역 누락은 영어로 안전하게 표시하며 키 문자열 자체를 사용자에게 노출하지 않는다.
