# WICHU UI·UX 가이드

## 시각 원칙

- 주요 탐색·상태·상품 아이콘은 동일한 시점과 광원의 3D 소프트 일러스트를 사용한다.
- 아이콘 고유의 의미가 먼저 읽혀야 한다. 브랜드 핑크는 선택·강조 상태에만 제한적으로 쓴다.
- 뒤로가기, 닫기, 체크, 화살표처럼 즉시 알아야 하는 조작 기호는 선명한 시스템 아이콘을 유지한다.
- 장식용 배경, 글로우, 과도한 그라데이션보다 사진과 실제 기능의 정보 위계를 우선한다.
- 모든 터치 영역은 최소 44pt를 확보하고 눌림 상태를 제공한다.

### 소프트 3D 아이콘 사용표

- 상태: 연결 오류, 검색 결과 없음, 사진 심사, 사진 반려
- 마이페이지: 발견 노출, 이용권, 프로필 사진 관리
- 기능: 번역, 안전, 알림, 위치, 광고 제거, 되돌리기
- 24~~32pt 포인트 아이콘은 배경 타일 없이 사용하고, 56~~82pt 상태 아이콘은 본문 앞에 단독 배치한다.
- 활성·비활성 여부는 아이콘 색을 임의로 바꾸지 않고 옆의 상태값, 점, 스위치로 표현한다.
- 의미가 같은 상태는 화면마다 다른 그림을 만들지 않고 `illustratedIcons`의 공통 자산을 재사용한다.

#### 이용권 아이콘 의미

- `goldPass`: Gold Pass 상품·구독·잠금 해제 안내
- `goldPremium`: Gold Pass를 이용 중인 사용자 프로필의 등급 배지
- `adFree`: Ad-Free 상품과 광고 제거 혜택
- `purchase`: 무료 이용권, 구매 복원, 결제 관리
- `discoveryVisible`: 발견 우선 노출과 프로필 공개 상태
- 이용권 등급별 공통 표시는 `getPassIllustration`을 사용해 화면마다 다른 아이콘이 섞이지 않게 한다.

## 카피 원칙

- 기능과 결과를 먼저 말한다: `최근 프로필 방문자를 확인합니다`.
- 분위기만 전달하는 문장과 추상적인 광고 문구를 쓰지 않는다.
- 빈 상태는 현재 상태, 발생 조건, 가능한 다음 행동 순으로 안내한다.
- 버튼은 `확인`, `메시지 보내기`, `Gold Pass 보기`처럼 실행 결과가 드러나는 동사를 쓴다.
- 같은 개념은 한 용어로 통일한다: `Pick`, `매치`, `방문자`, `발견`.

## 인터랙션 원칙

- 권한, 네트워크, 업로드 같은 외부 작업은 화면 이동을 막지 않고 백그라운드에서 처리한다.
- 저장·Pick·메시지는 즉시 화면에 반영하고 실패 시 원상 복구와 재시도 방법을 제공한다.
- 빈 상태와 오류 상태에서도 사용자가 이동할 다음 화면을 하나만 명확하게 제안한다.
- 중요한 안내는 한 번만 보여주고, 다시 볼 수 있는 설정 경로를 제공한다.

### 모달·바텀시트

- 하단에서 올라오는 기능 패널은 `InteractiveBottomSheet`를 사용한다. 시스템 `slide` 애니메이션을 화면마다 따로 적용하지 않는다.
- 바텀시트 딤은 최대 8%로 유지하고, 시트 이동량에 따라 함께 옅어진다. 콘텐츠를 검게 가리는 불투명 레이어는 쓰지 않는다.
- 핸들은 최소 44pt 터치 영역을 가진다. 탭은 펼침·줄임, 위로 밀기는 펼침, 아래로 밀기는 줄임, 빠르게 아래로 밀기는 닫기로 동작한다.
- 처리 중인 신고·저장처럼 중단하면 안 되는 작업은 제스처와 바깥 영역 닫기를 잠시 비활성화한다.
- 중앙 확인창은 18~22% 딤과 카드 그림자로 배경과 구분한다. 제스처 튜토리얼, Match 연출, 사진 전체보기처럼 몰입이 필요한 화면만 강한 딤을 허용한다.
- OS의 동작 줄이기 설정이 켜져 있으면 스프링·이동 애니메이션을 즉시 상태 전환으로 대체한다.

### 아이콘 모션

- 모션은 새 알림, 새 연결, Gold 혜택, 빈 상태처럼 상태 인지가 필요한 아이콘에만 적용한다.
- 한 번의 움직임은 약 0.4~~1.1초로 끝내고 2.4~~3.2초 쉬었다 반복한다. 계속 흔들리거나 회전하는 장식은 사용하지 않는다.
- 알림은 짧은 흔들림, 연결은 한 번의 박동, Gold는 작은 광택, 빈 상태는 4px 이내 부유 모션을 쓴다.
- 목록에 같은 아이콘이 여러 개 있을 때는 대표 아이콘 하나만 움직여 시선이 분산되지 않게 한다.
- 모든 아이콘 모션은 OS의 동작 줄이기 설정을 따른다.

### 앱 내 알림 배너

- 새 매치와 상대방의 새 메시지는 현재 화면을 막지 않는 상단 배너로 약 3초 표시한다.
- 배너를 누르면 관련 대화로 이동하고, 닫기 버튼 또는 위로 밀기로 즉시 닫을 수 있다.
- 동일 사건이 Push와 Realtime에서 함께 도착하면 한 건으로 합친다. 같은 대화의 연속 알림도 화면을 덮지 않도록 큐를 최대 4건으로 제한한다.
- 사용자 사진이 있으면 사진을 우선하고, 없으면 매치·메시지 공통 일러스트를 사용한다.
- 포그라운드에서는 앱 배너가 피드백을 담당하며 시스템 배너와 중복 표시하지 않는다.
