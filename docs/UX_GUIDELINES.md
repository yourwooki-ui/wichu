# WICHU UI·UX 가이드

## 시각 원칙

- 주요 탐색·상태·상품 아이콘은 동일한 시점과 광원의 3D 소프트 일러스트를 사용한다.
- 아이콘 고유의 의미가 먼저 읽혀야 한다. 브랜드 핑크는 선택·강조 상태에만 제한적으로 쓴다.
- 뒤로가기, 닫기, 체크, 화살표처럼 즉시 알아야 하는 조작 기호는 선명한 시스템 아이콘을 유지한다.
- 장식용 배경, 글로우, 과도한 그라데이션보다 사진과 실제 기능의 정보 위계를 우선한다.
- 모든 터치 영역은 최소 44pt를 확보하고 눌림 상태를 제공한다.

## 카피 원칙

- 기능과 결과를 먼저 말한다: `최근 프로필 방문자를 확인합니다`.
- 분위기만 전달하는 문장과 추상적인 광고 문구를 쓰지 않는다.
- 빈 상태는 현재 상태, 발생 조건, 가능한 다음 행동 순으로 안내한다.
- 버튼은 `확인`, `메시지 보내기`, `Gold Pass 보기`처럼 실행 결과가 드러나는 동사를 쓴다.
- 같은 개념은 한 용어로 통일한다: `Pick`, `매치`, `방문자`, `발견`.

## 인터랙션 원칙

- 권한, 네트워크, 업로드 같은 외부 작업은 화면 이동을 막지 않고 백그라운드에서 처리한다.
- 저장·Pick·메시지는 즉시 화면에 반영하고 실패 시 원상 복구와 재시도 방법을 제공한다.
- 빈 상태와 오류 상태에서도 사용자가 이동할 다음 화면을 하나만 명확하게 제안한다.
- 중요한 안내는 한 번만 보여주고, 다시 볼 수 있는 설정 경로를 제공한다.
